# gdd-unity

Unity Editor extension for [GDD Manager](https://github.com/Doublehitgames/GddApp).
The package lives in [`Packages/com.doublehitgames.gdd`](Packages/com.doublehitgames.gdd) —
see its [README](Packages/com.doublehitgames.gdd/README.md) for what it does and how
to install it.

The rest of this repository is a sandbox Unity project (6000.0) used to develop and
test the package. Open the repository root in Unity Hub to work on it.

> Early development — nothing to use yet.
